<behavior>
  - Test 1: Copies text via navigator.clipboard.writeText when available and returns true.
  - Test 2: When navigator.clipboard is undefined, creates a temporary hidden textarea, executes document.execCommand('copy'), removes the textarea, and returns true.
  - Test 3: When navigator.clipboard.writeText rejects, seamlessly falls back to execCommand.
  - Test 4: When both methods fail/throw, catches error and returns false without crashing.
</behavior>
