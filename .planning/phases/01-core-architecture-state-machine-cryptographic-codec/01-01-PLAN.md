## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Web Crypto API | In-memory key material and plaintext payload crossing browser crypto boundary |
| URL Hash -> Client Memory | Untrusted encrypted Base64 token from URL fragment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `src/crypto/greeting-codec.ts` | high | mitigate | Symmetrical AES-GCM 256-bit encryption with PBKDF2 key derivation (100k iterations, SHA-256). Payload stored in URL hash `#d=...` which is never transmitted to hosting servers in HTTP requests. |
| T-01-02 | Tampering | `src/crypto/greeting-codec.ts` | high | mitigate | AES-GCM 128-bit authentication tag verification during decryption; any bit flip in ciphertext causes immediate `OperationError` rejection. |
| T-01-03 | Elevation of Privilege | `src/crypto/greeting-codec.ts` | medium | mitigate | PBKDF2 derivation with 100,000 SHA-256 iterations imposes computational work factor (~15-25ms per attempt) preventing fast dictionary brute-forcing of 4-to-6 char passcodes. |
| T-01-SC | Tampering | npm installs (`lz-string`, `typescript`, `vite`, `tailwindcss`, `@tailwindcss/vite`, `vitest`) | high | mitigate | Verified packages audited in 01-RESEARCH.md package legitimacy table; zero malicious postinstall scripts; pinned trusted versions. |
</threat_model>
