## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Tampering / State Desynchronization | `src/graphics/scene-manager.ts` | Medium | mitigate | An uncancelled 1500ms `celebrationTimeoutId` could fire after component disposal or state replay, causing orphan FSM transitions or null reference errors. Mitigation: Track timeout handle in private field and explicitly call `clearTimeout()` on state change and during `dispose()` / `disposeSceneComponents()`. |
| T-05-05 | Denial of Service / Memory Leaks | `src/graphics/scene-manager.ts` | Low | mitigate | Retained DOM overlays, uncancelled animation frames, or unremoved window listeners across SceneManager, GreetingModal, and CelebrationManager cause memory exhaustion on low-memory mobile devices. Mitigation: Implement cascading `dispose()` unbinding all listeners, unmounting DOM nodes, resetting confetti, and clearing all timers per ASVS V14. |
| T-05-06 | Information Disclosure / Data Corruption | `src/ui/passcode-gate.ts` | Low | mitigate | Empty or truncated ciphertext payloads could result in undefined or NaN text fields. Mitigation: PasscodeGate and GreetingModal maintain robust fallback strings ('Dear Friend', 'A Well-Wisher', and default Diwali blessing) ensuring visual and structural stability. |
| T-05-SC | Tampering | npm dependencies | High | mitigate | Third-party dependencies verified against npm registry in Package Legitimacy Audit; pinned versions in package.json prevent unauthorized code execution. |
